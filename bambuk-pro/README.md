# Bambuk Pro

Настройка графики, цвета и производительности для ROB RUN (Windows, режим «Полноэкранный в окне»).
Tauri 2 + React + TypeScript + Rust. Файлы игры не меняются, в процесс игры ничего не внедряется.

## Сборка (на Windows)
1. Установите Rust (1.77+), Node.js 20+, Visual Studio Build Tools (C++), WebView2.
2. `npm install`
3. `npm run tauri build` → установщик в `target/release/bundle/nsis/`.
   Для разработки: `npm run tauri dev` из терминала **от администратора** (приложение просит права администратора для PresentMon).

## Что и как работает
| Раздел | Механизм |
|---|---|
| Potato Mode | Временная смена разрешения рабочего стола (`ChangeDisplaySettingsEx`, CDS_FULLSCREEN), подбор режима с тем же соотношением сторон и частотой |
| ColorTuner | Saturation, contrast, brightness, temperature, tint → матрица 5×5 (Magnification API); gamma → рампа GDI; vibrance → NVAPI Digital Vibrance; sharpness → overlay |
| Filters | Матрица цвета (чёрно-белый, сепия, инверсия, без синего, высокий контраст, усиление красного); overlay: Windows Graphics Capture + D3D11 + шейдер CAS |
| Performance | FPS, 1% Low, frame time: PresentMon (ETW); GPU: NVML; CPU: системные счётчики |
| Presets | JSON в `%APPDATA%\pro.bambuk.app`, экспорт/импорт, графика и цвет отдельно или единым профилем |

Каждая подсистема после применения проверяется чтением значения обратно; статус «Применено» ставится только при совпадении.
Откат: при закрытии, при выходе из игры, плюс файл `pending-revert.json` для восстановления гаммы и vibrance после аварийного завершения.

## Известные ограничения
- Цвет, гамма и разрешение действуют на весь основной монитор, а не только на игру.
- Magnification API конфликтует с Лупой и цветовыми фильтрами Windows.
- Overlay показывается только пока окно игры активно, добавляет задержку около кадра.
- Температура CPU не показывается (нужен сторонний драйвер ядра, риск для античита).
- Настройки внутри игры (тени, текстуры, детализация) недоступны без правки файлов или инъекции.

## Тесты
- `cargo test -p bambuk-core` — цветовая математика, статистика кадров, пресеты, подбор режимов, резервные копии.
- `npm test` — порт цветовой математики на TS совпадает с Rust.
